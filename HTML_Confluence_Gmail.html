Transforma Canvas de Gemini

Los Canvas de Gemini son un acelerador de prototipado de contenido: nos permiten pasar de texto plano a interfaces limpias, tablas sintetizadas, matrices interactivas y boletines visuales sin fricción técnica. Usa este estándar para decidir cuándo y cómo integrarlos.

Criterio Profesional

¿Cuándo amerita crear un Canvas?

No todo requiere un artefacto enriquecido. Aplica este marco mental de UX para no sobrecargar de trabajo ni generar fatiga visual innecesaria.

SÍ amerita un Canvas visual

Alto valor percibido y retención clave

  • ✓
    Reportes de User Testing a Stakeholders: Hallazgos, citas textuales sintetizadas, semáforos de severidad y métricas SUS que deben digerirse en 2 minutos.
  • ✓
    Handoff & Guías de Componentes en Confluence: Cuando una tabla plana no basta y necesitas fichas interactivas con estados, tokens y do's/don'ts visuales.
  • ✓
    Boletín mensual de Diseño / Release Notes: Correos de alto impacto hacia Developers y Product Managers con formato magazine/card.

NO amerita (Usa texto nativo)

Evita el overhead innecesario

  • ✕
    Minutas efímeras de syncs diarios: Texto con bullets nativos de Confluence es más rápido de editar colectivamente.
  • ✕
    Contenido que muta cada hora: Si varias personas deben editarlo en tiempo real, un macro HTML estático genera fricción.
  • ✕
    Avisos urgentes o incidentes: En un mail crítico o de alerta, prima la velocidad y legibilidad 100% plana sin carga de assets.

Workflow Oficial

El Flujo Paso a Paso de Producción

Desde la formulación del prompt en Gemini hasta la inserción limpia en tus canales habituales de trabajo.

PASO 01

Prompting con Arquitectura de Contenido

No le pidas a Gemini "hazme una página bonita". Dale contexto explícito: Rol + Destino (Confluence/Mail) + Datos en bruto + Restricciones de estilo (Single File, Tailwind, sin scripts externos complejos).

1
// Tips de diseñador:
"Genera un Canvas en 1 solo archivo HTML con Tailwind CSS. Incluye tarjetas de resumen, contraste accesible WCAG AA y estilo minimalista con paleta Slate e Indigo."
PASO 02

Edición e Iteración en la Vista Previa del Canvas

Aprovecha que Gemini despliega el código a la derecha y la previsualización interactiva. Revisa jerarquía tipográfica, márgenes y padding. Si algo sobra, pide podar texto: "Sintetiza los bullets a máximo 10 palabras cada uno y haz más prominentes los callouts".

2
Checklist de pulido visual:
  • ¿Los títulos se diferencian claramente del cuerpo?
  • ¿Se evitan párrafos de más de 4 líneas?
  • ¿Los iconos son SVGs inline simples (evitar fuentes rotas)?
PASO 03

Adaptación al Destino Técnico

Aquí ocurre la magia: si va a Confluence, copiamos el HTML limpio al macro HTML o creamos un iframe seguro. Si va a Email, le pedimos a Gemini convertir las clases a estilos inline CSS con tablas.

3
Ruta Confluence Macro HTML o Widget Embed con Tailwind cargado vía script.
Ruta Email Inline CSS (`style="..."`), sin JavaScript, anchos máximos de 600px.
PASO 04

Validación & Reutilización en el Equipo

Prueba la visualización en vista móvil (desktop y smartphone). Si el Canvas resuelve un patrón recurrente (ejemplo: ficha de investigación), guárdalo en nuestra librería de snippets compartida.

4
Regla de Oro Design Ops: "Si te tomó más de 15 minutos pulirlo, conviértelo en plantilla para el resto del equipo."
Guía de Adaptación Técnica

Cómo insertar Canvas según el Canal

Cada plataforma tiene restricciones distintas para renderizar HTML y CSS. Sigue estas especificaciones:

C Inserción en Confluence Cloud / Data Center

Opción 1
Macro HTML nativo (Recomendado): En el editor de Confluence, escribe /html. Pega el código del Canvas de Gemini. Si usas Tailwind, asegúrate de que el bloque HTML incluya la etiqueta <script src="https://cdn.tailwindcss.com"></script>.
Opción 2
Macro Iframe / Web Link: Si el Canvas requiere interactividad compleja con Javascript (acordeones avanzados o librerías), despliega el HTML en un bucket interno o GitHub Pages privado y enlázalo con el macro /iframe ajustando altura al 100%.
Opción 3
Copiado visual directo (Sin código): En la pestaña de previsualización de Gemini, selecciona con el mouse el contenido maquetado, presiona Ctrl/Cmd + C y pégalo directamente en Confluence. El editor enriquecido respetará tablas, colores de fondo básicos y estilos tipográficos limpios.
Tips de Estilo Confluence
Respeta el Design System de Atlassian

Usa fuentes del sistema (Inter, Segoe UI, Roboto) y colores neutros de fondo como #F4F5F7 para tarjetas para que el Canvas parezca nativo dentro de la página y no un bloque invasivo.

💡 Evita fijar anchos fijos en píxeles mayores a 800px para no romper la navegación responsiva de Confluence.

@ Emails Corporativos (Outlook, Gmail, Apple Mail)

⚠️ Regla crítica de clientes de correo: Los clientes de correo (especialmente Outlook) descartan archivos CSS externos, JavaScript y etiquetas <script>.
Paso 1
Solicitar a Gemini modo "Email Safe": Agrega a tu prompt: "Adapta este Canvas para correo: usa solo HTML con tablas de maquetación, estilos inline CSS (style='...'), ancho máximo de 600px centrado y sin JS."
Paso 2
Método de pegado inteligente: Abre la vista previa del Canvas en el navegador, selecciónalo visualmente con el mouse, copia y pega directamente en el cuerpo del correo en Outlook/Gmail. Mantendrá el diseño sin tocar código manual.
Restricciones Email
Límites Clave
  • • Ancho ideal: 600px centrado.
  • • Cero JS: Los botones deben ser enlaces <a href="..."> tipo pastilla.
  • • Imágenes: Usar URLs públicas seguras (HTTPS) con fallback alt="".
Siempre haz un "Send Test" a ti mismo y ábrelo en móvil antes del envío general.

Cheat Sheet Definitivo

Las Reglas de Oro para el Equipo UX/UI

Antes de compartir o integrar tu Canvas, valida esta lista de verificación técnica rápida:

1 Single-File Mandate

Nunca uses links externos a archivos .css o .js locales. Todo debe ir autocontenido para que Confluence o tus correos no queden rotos.

2 Sintetiza el contenido primero

La estética no rescata un texto confuso. Si un bullet pasa de 3 líneas, pídele a Gemini que lo resuma antes de trabajar en los componentes.

3 Usa SVGs inline para iconos

Evita librerías de fuentes de iconos que requieran descargas de CDN lentas o bloqueadas por firewalls corporativos.
