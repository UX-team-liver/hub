LIVERPOOL UX

Objetivo Estratégico

Evolucionar la plataforma corporativa de inversión "Liverpool Venture" hacia una arquitectura robusta orientada a Next.js. Mediante la implementación de un enfoque de diseño híbrido y metodologías atómicas (piezas de Lego), garantizaremos interfaces de alta eficiencia ejecutiva, facilitando la escalabilidad visual y técnica a lo largo de todo el ecosistema.

Alcances del Proyecto (Módulos Core)

  • Consolidación del ecosistema en secciones dedicadas: Home kanban, Time Machine y AI Prompt Tweaker.
  • Rediseño estructural para gestores operativos: Connections Manager, Ecosystem Contacts Manager y Task Manager.
  • Optimización de sistemas de interacción pasiva/activa: Notificaciones y Partner Feedback.
  • Validaciones continuas: Sesiones OPEN UX con Managers y Subdirectores para mitigar riesgos en etapas tempranas [cite: 2].

Capacidades a Desarrollar (Por Módulo)

1. Discovery de la Plataforma

Inmersión técnica y de negocio.

  • Definir approach con SH interno y crear brief de diseño [cite: 2].
  • Sesiones de 1 hora diaria de explicación a profundidad del ecosistema actual.
  • Definir hipótesis, user personas y trazar el mapa de navegación macro [cite: 2].

2. Home Kanban & Time Machine

El núcleo de gestión visual.

  • Traducir insights del negocio en journeys para el flujo de oportunidades [cite: 2].
  • Crear wireframes y prototipos atómicos para las tarjetas (Kanban) y línea de tiempo (Time Machine) [cite: 2].
  • Ejecutar validación (OPEN UX) con Manager y Subdir para ajustar iteraciones [cite: 2].

3. AI Prompt Tweaker

Optimización de inputs para LLM.

  • Arquitectura de información para la gestión de prompts.
  • Garantizar consistencia visual de inputs utilizando la biblioteca de Figma (GLUE Owner) [cite: 2].
  • Test de usabilidad conceptual y especificaciones para Devs [cite: 2].

4. Connections & Contacts Mgr

Gestión de redes y partners.

  • Diseñar flujos de filtrado y visualización de datos de redes.
  • Proporcionar datos analíticos para decidir iteraciones en vistas de tablas/listas [cite: 2].
  • Verificar estándares de calidad (DS) y documentar componentes [cite: 2].

5. Task Manager & Notificaciones

Productividad y alertas asíncronas.

  • Crear prototipos de alta fidelidad para el centro de tareas [cite: 2].
  • Diseñar el sistema de notificaciones no intrusivo y estados vacíos (empty states).
  • Revisar que los diseños estén especificados para Devs antes del hand-off [cite: 2].

6. Partner Feedback & Evolución

Cierre de ciclo y mejora continua.

  • Diseñar módulo de retroalimentación e ingesta de incidencias.
  • Supervisar alineación transversal con QA (evaluando riesgos/trade-offs con SH) [cite: 2].
  • Analizar métricas (Data Runners) post-lanzamiento para detectar mejoras en el HOME [cite: 2].

Dependencias Técnicas

El éxito de esta implementación requiere una alineación perfecta con las áreas de ingeniería. Supervisaremos la viabilidad transversal con Devs y QA, evaluando riesgos técnicos y trade-offs en conjunto con Stakeholders (SH) para garantizar que las especificaciones UX sean viables en el framework [cite: 2].
